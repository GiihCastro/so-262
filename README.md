# Sistemas Operacionais — SO-262

Repositório destinado ao armazenamento e organização das atividades desenvolvidas na disciplina de **Sistemas Operacionais (SO-262)**.

## 📁 Estrutura do repositório

As atividades da disciplina estão organizadas na pasta `avaliações`, separadas individualmente conforme sua numeração:

```text
so-262/
│
├── avaliações/
│   ├── atividade-01/
│   │   └── README.md
│   ├── atividade-02/
│   │   └── README.md
│   ├── atividade-03/
│   │   └── README.md
│   ├── atividade-04/
│   │   └── README.md
│   ├── atividade-05/
│   │   └── README.md
│   ├── atividade-06/
│   │   └── README.md
│   ├── atividade-07/
│   │   └── README.md
│   ├── atividade-08/
│   │   └── README.md
│   ├── atividade-09/
│   │   └── README.md
│   └── atividade-10/
│       └── README.md
│
└── README.md
```

Cada pasta de atividade possui um arquivo `README.md` destinado à descrição da atividade correspondente, incluindo seus objetivos, requisitos e, posteriormente, a implementação e os resultados obtidos.

## 🎯 Objetivo

Este repositório tem como objetivo **centralizar, organizar e documentar** as atividades realizadas ao longo da disciplina de Sistemas Operacionais, facilitando o acompanhamento do desenvolvimento e dos resultados de cada avaliação.

> As atividades serão atualizadas conforme forem propostas e realizadas durante a disciplina.
